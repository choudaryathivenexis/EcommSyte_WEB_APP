## 1. What this is

A **static marketing website** for **ecommsyte**, a full-service Amazon growth agency.
Tagline: *"Strategy-Driven Amazon Growth."*

- **Stack:** Plain HTML + one CSS file + one JS file. **No framework, no build step, no
  package manager, no dependencies.**
- **Not a git repository.** No `package.json`, `node_modules`, `robots.txt`, or `sitemap.xml`.
- **Run locally:** `python -m http.server 5599` (see [.claude/launch.json](.claude/launch.json)).
- **Deploy:** Upload the static files to any host. Intended domain: `https://www.ecommsyte.com/`.

## 3. Architecture & conventions

### Multi-page, no templating
- Each page is a standalone `.html` file. Navigation is plain `<a href="page.html">` links.
- **The `<header class="nav">` and `<footer class="footer">` markup is duplicated in
  every HTML file.** There is no include/template system.
  ⚠️ **A change to nav or footer must be repeated across all 7 pages.**
- The active nav link uses `class="nav__link is-active"` + `aria-current="page"` per page.

### CSS ([styles.css](styles.css))
- **Design tokens** live in `:root` at the top (lines ~14-44). Change brand look there.
- **6-color brand palette:**
  | Token | Hex | Role |
  |-------|-----|------|
  | `--orange` | `#E6862D` | Primary / CTA / highlights |
  | `--ink` | `#1D1E20` | Dark surfaces / hero / footer / text |
  | `--white` | `#FFFFFF` | Cards / surfaces |
  | `--cream` | `#F6F1E9` | Warm alt sections |
  | `--amber` | `#F2A65A` | Gradient partner / soft accents |
  | `--mist` | `#9AA3AE` | Cool supporting / charts |
- Other tokens: `--radius`, `--radius-sm`, `--shadow-sm/md/lg`, `--grad-warm`,
  `--grad-cool`, `--container` (1180px), `--ease`, plus derived ink tints and `--muted`.
- **Fonts:** `--ff-head` = Sora, `--ff-body` = Inter (Google Fonts, loaded per page in `<head>`).
- **Naming:** BEM-style — block `.scard`, element `.scard__icon`, modifier `.plan--featured`.
- Utility/behavior hook classes used by JS: `.reveal`, `.tilt`, `.magnetic`, `.parallax`
  (with `data-depth`), `.js-open-modal`, `.rcard[data-count]`.
- **Icons: no emoji anywhere.** All icons are a unified inline **line-icon system** —
  `<svg class="ico" viewBox="0 0 24 24" aria-hidden="true">…</svg>`, 2px stroke,
  `currentColor`, sized to `1em` of its context (so chips/lists control size via
  `font-size`). Color is set by context in styles.css: dark glass chips (`.scard__chip`,
  `.subcard__glyph`, `.pcard__chip`) → white; value tiles / hero float (`.scard__icon`,
  `.fc__icon`) → orange; blog thumbs follow `.bcard__thumb`(`--dark` → white). The 50-icon
  library + the emoji→icon mapping live in `scratchpad/gen_icons.py` — to change an icon,
  edit that dict and re-run (it rewrites the inline SVGs across all HTML). A few icons are
  also inline in script.js (modal lock).
- **Premium image banners (CSS/SVG, no image files):** service cards on the homepage use
  `.scard__banner` (full-bleed gradient + grid texture, themed by
  `--banner-glow` via `.scard__banner--{launch|research|sourcing|listing|creative|ppc|health|channel}`),
  an inline `.scard__art` SVG "data-art" motif, and a frosted glass `.scard__chip` holding
  the emoji. The same `.scard__art` layer + `.bcard__glyph` are reused inside blog thumbs.
  All banners are self-contained (no external assets), on-brand, and scale subtly on hover.
- **Services page sub-cards (`.subcard`)** share the same premium banner language:
  `.subcard__banner` (dark ink gradient + grid texture + `--sub-glow` rhythm via
  `:nth-child(5n+…)`), a frosted glass `.subcard__glyph` chip, an editorial
  `.subcard__index` corner numeral, and a **unique per-card SVG data-URI motif** — each of
  the 40 sub-services has its own bespoke motif that depicts that specific service (e.g.
  checklist for compliance, gears for production, gauge for metric improvement, scales for
  appeals), applied via `#<section> .subcard:nth-child(N) .subcard__banner::after`. This is
  **CSS-only** — the 40 sub-card HTML blocks were not changed. All 40 motifs are generated
  by `scratchpad/gen_motifs.py` (readable SVG source → URL-encoded → written into the
  motif block in styles.css). To change/add a motif, edit that script's `motifs` dict and
  re-run it; it replaces the whole motif block in place.

### JavaScript ([script.js](script.js))
One file, two IIFEs. Everything is progressive enhancement and degrades gracefully;
all motion respects `prefers-reduced-motion` and disables on touch (`hover: none`).

| # | Feature | Notes |
|---|---------|-------|
| 1 | Preloader | Animated % counter; hard 4.5s fallback so it never blocks the page (`#preloader`, `is-loading` body class). Only on `index.html`. |
| 2 | Nav | Scrolled state (`.scrolled` after 24px), scroll-progress bar (`#scrollProgress`), mobile hamburger (`#navToggle` / `#navLinks`) with backdrop, Escape-to-close, focus return. |
| 3 | Scroll reveal | IntersectionObserver adds `.in` to `.reveal` elements. |
| 4 | Counters | `.rcard[data-count]` counts up when scrolled into view; reads `data-count`, `data-suffix`, `data-prefix`. |
| 5 | 3D tilt | `.tilt` cards follow the pointer (desktop only). |
| 6 | Magnetic buttons | `.magnetic` elements drift toward the cursor. |
| 7 | Parallax | `.parallax` orbs translate on scroll by `data-depth`. |
| 8 | Hero scene | `#heroScene` rotates subtly with pointer (homepage). |
| 9 | Forms | `setupForm()` on `#bookingForm`, `#contactForm`, `#newsletterForm` + the modal form. Client-side validation (`.field` / `.invalid` / `.field__error`) + Formspree AJAX POST with `.form__status` messaging. Guards against unconfigured `YOUR_` endpoints. |
| 10 | CTA modal | Built in JS (`initModal`), appended to `<body>`. Opens on any `.js-open-modal` or `a[href$="#book"]`. Reads `data-cta` / `data-service` off the trigger to pre-fill the service. Full focus-trap + Escape + overlay close. |
| 11 | FAQ accordion | Native `<details class="faq__item">`; opening one closes siblings within a `.faq`. |
| 12 | Social sidebar tray | Separate IIFE builds `.social-tray` (fixed left rail) and appends it to `<body>` on every page. Links/icons defined in the `LINKS`/`ICONS` maps in script.js (per-icon viewBox via `VIEWBOX`) — uses the site's `YOUR_HANDLE` / WhatsApp placeholders. Hover reveals a slide-out label + brand-colour fill. Hidden below 992px (footer socials cover mobile). |
| — | Footer year | Fills `#year` with the current year. |

### Forms (Formspree)
- Provider: **Formspree** (AJAX `fetch` POST, expects JSON). No backend of our own.
- Endpoints are placeholders — see [Placeholders](#5-placeholders--must-configure-before-launch).
- Field names submitted: `name`, `email`, `store`, `revenue`, `service`, `message`,
  and hidden `interest` (modal only).

### SEO / metadata
- Every page: unique `<title>` + `meta description`, `canonical`, Open Graph, favicon.
- Homepage also has Twitter Card meta + a schema.org `Organization` JSON-LD block.
- `theme-color` = `#1D1E20`.

## 4. Page-by-page section inventory

- **index.html:** preloader → nav → hero (3D dashboard visual) → capabilities marquee →
  8-service preview grid (each card has a premium SVG-art banner) → 4-step process →
  results/counters → **brand-logo marquee (`.logos`, real `<img>` logos from
  `assets/logos/`)** → case studies → testimonials preview →
  team → **blog/insights section (`#insights`, 3 `.bcard` articles linking to blog.html)**
  → CTA band → footer.
- **Brand marquee (`.logos`)**: two auto-scrolling `.logo-track` rows of `<img class="logo-item">`
  pulling 16 original SVG marks from `assets/logos/` (each row duplicated for a seamless
  loop; muted "logo wall" that brightens on hover). Fully responsive (logo height via
  `clamp`); under `prefers-reduced-motion` it collapses to a single static centered wrapped
  grid. The SVGs are original designs for the site's own placeholder brand names — **to use
  real client logos, drop files with the same names into `assets/logos/`** (or edit
  `scratchpad/gen_logos.py` and re-run). Keep each logo a single dark color so the
  muted-wall + hover effect reads correctly.
- **Team cards (`.tm`, used on index.html + about.html — keep both in sync)**: a premium
  portrait-card. Top is a `.tm__photo` media block (5:6, branded gradient + grid texture +
  bottom fade; `--warm` / `--ink` variants alternate) holding an `<img class="tm__portrait">`
  from `assets/team/` (elegant frosted-bust SVGs — transparent bg so the gradient shows
  through, so they work on both variants), a frosted-glass `.tm__chip` monogram, and a
  hover-reveal `.tm__social` LinkedIn button (currently the placeholder company URL). Below
  is `.tm__body` with name, a `.tm__role` pill, and bio. Portraits are generated by
  `scratchpad/gen_team.py`; **to use real headshots, drop photos at `assets/team/<mq|ha|zf|uk>.svg`
  (or swap the `src` to `.jpg`/`.webp`)** — `object-fit: cover` handles the crop.
- **Case-study cards (`.pcard`)**: the 3 result thumbnails (`.pcard__thumb`) are premium dark
  result "images" — inline `.pcard__art` SVG charts that depict each case's metric
  (declining ACoS + rising orders, rising conversion curve, rank-climb to page 1) over a
  gradient + grid + glow, with a frosted `.pcard__chip` emoji and the `.pcard__delta` badge.
  The featured card's `.pcard__media` got matching grid texture + glow.
- **services.html:** page-hero → 8 detailed service sections
  (`#launch`, `#research`, `#sourcing`, `#listing`, `#creative`, `#ppc`, `#health`,
  `#multichannel`) alternating `.section` / `.section--alt`, each with 5 `.subcard`
  sub-services (40 total) that carry premium dark SVG-motif banners → pricing `#plans`
  (**Ignite** from $1.5k/mo · **Accelerate** from $3.5k/mo, "Most popular" · **Dominate**
  custom) → footer. Plan buttons use `.js-open-modal` with `data-cta`.
- **about.html:** page-hero → story → mission/values → results/counters → team → journey timeline.
- **testimonials.html:** page-hero → testimonials grid → results.
- **blog.html:** page-hero → article grid (7 `.bcard` **image cards** linking to full posts) →
  newsletter signup (`#newsletterForm`, `#n-email`).
- **blog-*.html (7 posts):** premium two-column editorial layout — cinematic `.post-hero`
  (category, big title, author byline with portrait) → overlapping `.post__cover` Unsplash
  image → `.post__grid` = **sticky `.post__rail`** (auto-generated **table of contents** with
  scrollspy + **share** buttons: X, LinkedIn, copy-link) beside `.post__body` prose (lead,
  H2/H3 with accent markers, lists, blockquote, dark `.post__takeaways`) → in-article CTA →
  **`.post__author-card`** (team portrait + bio) → tags → related posts → CTA band. Unique SEO
  meta + `BlogPosting` JSON-LD per post. The rail collapses to a boxed inline TOC below 1024px.
  TOC scrollspy + copy-link handlers live at the end of script.js (guarded, no-op off-article).
  **All 7 posts + the blog grid + homepage `#insights` cards are generated from
  `scratchpad/gen_blogs.py` + `gen_blogs2.py`** (run gen_blogs2 to rebuild). Hero images are
  **verified** `images.unsplash.com` photo IDs (checked HTTP 200 before use). Post styling is
  under the "BLOG — image cards + article (post) pages" block in styles.css.
- **careers.html:** page-hero → culture (`#culture`, 6 value cards) → results →
  open roles (`#roles`, 6 positions) → hiring process.
- **contact.html:** page-hero → booking form (`#book` / `#bookingForm`) →
  contact info + quick message (`#contactForm`) → FAQ (`<details>`).

Anchor links used across the site: `contact.html#book` (opens the modal / booking form),
and `services.html#<service-id>` from nav/footer/service cards.

## 7. Maintenance checklist

- [ ] Added/removed/renamed a **page** → update the [File map](#2-file-map) and
      [Section inventory](#4-page-by-page-section-inventory).
- [ ] Changed **nav or footer** → confirm the change was applied to **all 7 HTML files**
      (they are duplicated) and note it here if the structure changed.

- [ ] Added/removed a **JS feature or behavior hook class** → update the JS table in §3.
- [ ] Changed **forms** (fields, endpoints, provider) → update §3 forms + §5 placeholders.
- [ ] Resolved a **`YOUR_` placeholder** → tick it off / remove the row in §5.
- [ ] Introduced tooling (git, a build step, `package.json`, sitemap) → update §1 and §6.
- [ ] Update the **"Last verified against source"** date at the top.
